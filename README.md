# ThicketHubFront - Central de Chamados

Frontend do sistema central de chamados institucional com SLA, filas de atendimento por setor e perfis de acesso (Superusuário, Administrador, Técnico, Usuário).

## Tecnologias

- **TanStack Start** (React 19 + TypeScript)
- **TanStack Router** & **TanStack Query**
- **Tailwind CSS v4** & **Radix UI** / **shadcn/ui**
- **Supabase**
- **Vitest** (Testes Unitários e de Integração)
- **Playwright** (Testes End-to-End)

## Desenvolvimento

```sh
# Instalação das dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Executar testes unitários e de integração
npm test

# Executar testes E2E
npm run test:e2e

# Build de produção
npm run build
```
